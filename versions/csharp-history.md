# C# language history index

C# evolves on its own release timeline. A feature may be compiler-only, may
need a library API, or may depend on runtime behavior; it is not automatically
a feature of the .NET release that shares its number. The default C# version
depends on the target framework and compiler. See Microsoft's
[C# language versioning guidance](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/language-versioning)
and [official language history](https://learn.microsoft.com/en-us/dotnet/csharp/whats-new/csharp-version-history)
for the source of truth.

The table is a navigation index, not a claim that all tutorials are complete.

## Coverage checklist

Each version's completed entry will include its exact release date, feature
catalog, motivation, before/after code, compiler and target requirements,
runtime/library dependencies, and official references. Significant features
will link to dedicated tutorials and runnable examples. Until those are
created, this index deliberately does not imply that a version is complete.

Important cross-version topics to follow include nullable reference types,
records, pattern matching, async/await and cancellation, file-scoped
namespaces, global usings, collection expressions, extension members,
interpolated string handlers, and project-system evolution.
